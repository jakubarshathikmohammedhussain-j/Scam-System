## 📖 DIRECTIVE
The **S.C.A.M. SYSTEM** is an elite, AI-driven enterprise analytics terminal designed to detect software redundancy, visualize overlapping tools, and calculate wasted run-rate spend. Powered by the Google Gemini 3.5-Flash-Lite neural engine, it acts as a hyper-analytical Corporate CIO, delivering actionable mitigation strategies and synthesizing them into dynamic audio briefings.

---

## ✨ NEURAL CAPABILITIES

*   **Cyberpunk HUD Matrix:** A fully custom, CSS-injected Corporate Anime user interface featuring neon pulsing headers, hover-glow state buttons, and obsidian data containers.
*   **Dual Data Ingestion:** Upload CSV inventory cores or manually inject raw text logs.
*   **Structured AI Output:** Enforces strict JSON schemas at the API level for flawless data extraction and ledger creation.
*   **Holo-Analytics Topography:** Interactive Plotly Treemaps visualize software sprawl and financial waste across departmental silos.
*   **Dynamic Audio Synthesis:** Integrates `gTTS` (Google Text-to-Speech) entirely in-memory to generate immediate audio briefings and executive diagnostic commands.
*   **Ghost Token Authentication:** Features a secure cloud vault with a URL query-parameter backdoor, allowing the creator seamless access while enforcing a strict API-key wall for public visitors.
